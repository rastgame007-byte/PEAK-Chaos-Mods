PeakMods для PEAK — установка
==============================

1. Закрой игру.
2. Распакуй архив (сначала «Извлечь всё», не запускай из окна архива).
3. Всё содержимое папки 1_COPY_INTO_GAME_FOLDER скопируй в корневую папку PEAK
   (Steam -> правой кнопкой по PEAK -> Управление -> Просмотреть локальные файлы).
   Рядом с PEAK.exe должны лежать: winhttp.dll, doorstop_config.ini и папка BepInEx.
   Спросит про замену файлов — соглашайся.
4. Если у тебя уже был PeakFun (читы) и ты хочешь играть честно — удали BepInEx\plugins\PeakFun.dll.
   PeakMods с ним не конфликтует, но тогда в игре останутся читы.
5. Запусти игру. В лагере/забеге жми F1 — меню PeakMods. F2 — список модификаторов на экране.

Как играть отрядом:
 - PeakMods должен стоять у ВСЕХ друзей.
 - Один из вас в вкладке «Забег» выбирает набор (галочки / пресет / случайный набор / драфт карт) и жмёт
   «НАЧАТЬ ЗАБЕГ ДЛЯ ВСЕГО ОТРЯДА». Набор появляется у всех одинаковый и блокируется — ни у кого нет выключателей.
 - Закончить забег для всех может только тот, кто его запустил.
 - Итог забега: BepInEx\PeakMods_run_last.txt.
 - Один: вкладка «Забег» — «НАЧАТЬ ЗАБЕГ» (рассылка не нужна).

Проверка: вкладка «Проверка» -> «Запустить проверку». Отчёт: BepInEx\PeakMods_check_latest.txt.
Если что-то не работает — пришли BepInEx\LogOutput.log и этот отчёт.

Настройки: BepInEx\config\com.friends.peakmods.cfg (клавиши, масштаб, приём набора от друзей).

Удалить мод: убери PeakMods.dll из BepInEx\plugins (или всю папку BepInEx + winhttp.dll + doorstop_config.ini).

Если уже стоит BepInEx 5 — достаточно положить PeakMods.dll в BepInEx\plugins.
Linux/Steam Deck: в параметрах запуска Steam впиши  WINEDLLOVERRIDES="winhttp=n,b" %command%
Антивирус иногда ругается на winhttp.dll (часть BepInEx) — добавь папку игры в исключения.
