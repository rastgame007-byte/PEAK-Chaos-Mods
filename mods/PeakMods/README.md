# PeakMods 1.0.0 — прохождение PEAK с модификаторами

Отдельный мод для BepInEx 5. **Не чит-меню**: вы выбираете набор правил (легче / сложнее / веселее) и проходите гору отрядом. Набор общий для всех и после старта заблокирован — ни у кого нет выключателей.

> **Важно: мод не запускался в самой игре** (у автора нет доступа к игре). Он собран и проверен только по коду. Вкладка «Проверка» в меню покажет, что работает, а что нет. Если что-то не так — пришлите `BepInEx\LogOutput.log` и `BepInEx\PeakMods_check_latest.txt`.

## Установка
Подробно — `INSTALL_RU.txt`. Коротко: распаковать архив → содержимое `1_COPY_INTO_GAME_FOLDER` в папку с `PEAK.exe` → запустить игру → **F1**.
Если стоит PeakFun и нужны честные забеги — удалите `BepInEx\plugins\PeakFun.dll`.

## Как играть
1. **F1** — меню. Вкладка **«Забег»**.
2. Соберите набор любым способом:
   - **галочки** в вкладках категорий (слева);
   - **пресет** — «Прогулка», «Классика+», «Выживание», «Командная работа», «Ночной подъём», «Хаос-лотерея», «Кошмар»;
   - **случайный набор** — целевая сложность + число модификаторов + seed (тот же seed — тот же набор);
   - **драфт карт** — на старте и в каждом новом биоме отряд голосует, какую из трёх карт (польза / проклятие / джокер) добавить. Решает большинство, ничья — по жребию.
3. Один из вас жмёт **«Начать забег для всего отряда»**. У всех появляется одинаковый набор.
4. **F2** — список модификаторов на экране: кратко / подробно / скрыт.
5. Закончить забег для всех может запустивший. Итог — `BepInEx\PeakMods_run_last.txt` (время, биомы, падения, набор, журнал).

Один без друзей: «Начать забег» работает и в одиночку.

## Сложность
У каждого модификатора есть очки: минус — легче, плюс — тяжелее. Сумма даёт ярлык: ≤ −6 «для отдыха», −5…−1 «лёгкий», 0…5 «обычный», 6…12 «сложный», 13…20 «жёсткий», выше — «кошмар».

## Синхронизация
- PeakMods нужен **у всех**. У кого его нет — правила на нём не действуют.
- События (ветер, камнепад, ледяные порывы, приливы) считаются по общему seed и общему времени (UTC), поэтому у всех происходят одновременно.
- Хост-запускатель каждые 15 секунд повторяет набор — кто зашёл позже, подхватит его.
- Канал: Photon-событие 112 (не пересекается с PeakFun, у которого 111).

## Что внутри
- Только рефлексия: мод не ссылается на DLL игры и собирается без неё.
- Каждый модификатор запускается в `try/catch`; после 8 ошибок подряд он сам отключается (в HUD пометка «сбой»), остальные продолжают работу.
- Вкладка «Проверка» делает «сухой» прогон всех модификаторов без изменения мира.
- Исходники — папка `source`. Сборка: `dotnet build -c Release` (нужны BepInEx.dll и 0Harmony.dll в `../libs`).

## Известные риски (не проверено в игре)
- Имена статусов и аффликций (`AddStatus`, `Affliction_*`) взяты из публичных декомпиляций игры; после обновления PEAK могут измениться.
- Место для мин и ядовитых зон берётся с поверхности карты (Terrain); если найти его не удалось — эти модификаторы просто ничего не ставят.
- Угол обзора (FOV) может перебиваться самой игрой.

Мод для приватных игр с друзьями. BepInEx 5.4.23.3 (LGPL).

## Сборка из исходников

Готовый мод лежит в папке `downloads/` в корне репозитория (скачай `.zip`, внутри инструкция `INSTALL_RU.txt`). Собирать самому не обязательно.

Если хочешь собрать: положи `BepInEx.dll` и `0Harmony.dll` (из BepInEx 5) в папку `libs/`, затем `cd src && dotnet build -c Release`. Типы игры PEAK подхватываются рефлексией, DLL игры не нужны.

В релизный архив входит BepInEx (LGPL-2.1) — проект [BepInEx](https://github.com/BepInEx/BepInEx). Мод неофициальный, к разработчикам PEAK отношения не имеет. Использовать только в приватных лобби с согласия друзей.
