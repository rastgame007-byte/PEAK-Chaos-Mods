# PeakJujutsu — «Магическая битва» для PEAK

Одиночный мод (BepInEx 5, C#): шесть персонажей аниме с настоящими техниками, охота на проклятия с боссами,
прокачка, доменные расширения, собственные 3D-модели врагов и эффекты. Всё процедурное — без внешних ассетов.

| Персонаж | Z | X | V | G | Ультимейт (H) |
|---|---|---|---|---|---|
| Годжо | Синий | Красный | Фиолетовый | Бесконечность | Безграничная пустота |
| Сукуна | Рассечение | Разруб | Огненная стрела | Рывок Хэйан | Храм Злобы |
| Юдзи | Расходящийся кулак | Чёрная вспышка | Манджи-кик | Усиление ЦЭ | Серия вспышек |
| Мегуми | Божественные псы | Нуэ | Максимальный слон | Шаг в тени | Сад теней + Махорага |
| Тодо | Буги-Вуги | Хлопок | Серия ударов | Лучший друг | Вихрь хлопков |
| Нанами | Соотношение 7:3 | Обрушение | Сверхурочная | Рывок клинка | Жёсткий предел |

Враги: огоньки, проклятые псы, летающие головы, громилы; боссы — Дзёго, Ханами, Махито, Сукуна, Годжо.
Меню — F4. Установка — `INSTALL.bat` или см. `INSTALL_RU.txt`. Исходники — папка `source`.

Статус: компилируется (0 ошибок, 0 предупреждений), в живой игре ещё не тестировался.

## Сборка из исходников

Готовый мод лежит в папке `downloads/` в корне репозитория (скачай `.zip`, внутри инструкция `INSTALL_RU.txt`). Собирать самому не обязательно.

Если хочешь собрать: положи `BepInEx.dll` и `0Harmony.dll` (из BepInEx 5) в папку `libs/`, затем `cd src && dotnet build -c Release`. Типы игры PEAK подхватываются рефлексией, DLL игры не нужны.

В релизный архив входит BepInEx (LGPL-2.1) — проект [BepInEx](https://github.com/BepInEx/BepInEx). Мод неофициальный, к разработчикам PEAK отношения не имеет. Использовать только в приватных лобби с согласия друзей.
